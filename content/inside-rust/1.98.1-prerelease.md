The 1.98.1 pre-release is ready for testing. The release is scheduled for
September 3. [Release notes can be found here.][relnotes]

You can try it out locally by running:

```
RUSTUP_DIST_SERVER=https://dev-static.rust-lang.org rustup update stable
```

The index is <https://dev-static.rust-lang.org/dist/2026-09-02/index.html>.

You can leave feedback on the [internals thread](https://internals.rust-lang.org/t/rust-1-98-1-pre-release-testing/24573).

General feedback about our pre-release process is welcome [on this GitHub issue][feedback].
